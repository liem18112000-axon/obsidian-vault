# Payrexx ISO 8583 decline code to meaning reference table

Reference: Payrexx official merchant-doc mapping of ISO 8583 decline codes to their merchant-facing meaning. The code is generated by the card-issuing bank, not by Payrexx. Source for the LUZ-157809 code->category taxonomy. NOTE these "Meaning" strings are Payrexx documentation text — they are NOT the same as the short prose that arrives on the transaction API `message` field (e.g. API returns "An error occurred: Your card has expired." while the doc meaning for 54 is the longer sentence below).

| Code | Meaning |
|---|---|
| 01 | Issuer declined; cardholder should contact issuing bank |
| 03 | Entered data incorrect; customer should retry |
| 04 | Declined; card may be lost/stolen, retention requested; use different card / contact bank |
| 05 | Issuer unwilling to accept; use alternative card / contact bank |
| 06 | Possibly mis-flagged as fraudulent; contact bank or try new card |
| 07 | Declined; card possibly reported lost/stolen |
| 10 | Partial authorization only; remainder needs another payment method |
| 12 | Card processing error; check payment options configuration |
| 13 | Invalid data (negative amount / invalid characters); resubmit |
| 14 | Card number entered incorrectly or does not exist; verify and retry |
| 15 | Card issuer does not exist; verify details and retry |
| 19 | Processing temporarily unavailable (Visa); retry later |
| 22 | Issuing bank did not respond; verify details and retry |
| 31 | Card unusable for mail/phone/fax/email/online orders (typical Discover); use alternative |
| 34 | Suspected fraud on card number; if repeated contact Payrexx |
| 41 | Cardholder reported card lost/stolen; refer to bank, do not fulfill |
| 42 | Invalid account type for this card number; use different card / contact bank |
| 43 | Cardholder reported card stolen; refer to bank, do not fulfill |
| 46 | Account closed / validation issue; contact bank |
| 51 | Insufficient funds or credit limit exceeded; use alternative / contact issuer |
| 54 | Card expired; update card details or use different card |
| 55 | Incorrect PIN; re-enter or use alternative |
| 56 | Card number does not exist; use different card |
| 57 | Card not accepted for this transaction type; use different card / contact bank |
| 58 | Card unusable for this transaction type (often test card in live mode) |
| 59 | Flagged fraudulent; monitor subsequent transactions, contact Payrexx support |
| 61 | Amount exceeds issuer withdrawal limit |
| 62 | Card invalid in region/country or no online support; use different method |
| 63 | Security issue detected on card; use alternative or retry after resolving with bank |
| 65 | Card activity limit reached; use different method |
| 67 | Suspected counterfeit card; use different card and contact bank |
| 70 | Secure customer authentication required; retry with PIN (Visa) |
| 75 | Max incorrect-PIN attempts exceeded; retry or use different method |
| 78 | Account for this card number does not exist; use different card |
| 79 | Incorrect card info / suspected fraud (Mastercard) |
| 80 | Invalid card expiration date; verify and retry |
| 82 | CVV/CID/CVC mismatch; verify and retry |
| 83 | Suspected fraud (Mastercard) |
| 84 | Logical/timing error in authorization lifecycle; use alternative method |
| 86 | PIN could not be validated; retry without PIN or contact bank |
| 91 | Issuing bank unreachable to authorize; retry or contact bank |
| 92 | Card could not be located for processing; retry |
| 93 | Issuing bank does not allow this transaction; use different method |
| 96 | Issuing bank temporarily unavailable (system failure); retry or use different method |
| 1A | Authentication required (Visa); retry via 3-D Secure if not PSD2/3DS already |
| 6P | Account verification failed (Visa Direct); contact bank |
| N4 | Amount exceeds issuer withdrawal limit; use different method |
| N7 | CVV2 mismatch; retry |
| P1 | Issuer temporarily unavailable; retry later |
| R | Cardholder cancelled this one-time recurring payment (Visa); contact customer |
| R1 | Cardholder requested stop of all recurring payments (Visa); contact customer |
| R3 | All recurring payments for this card number cancelled (Visa); contact customer |

Draft category grouping (feeds LUZ-157809): insufficient-funds {51,61,65,N4,10}; card-expired {54}; blocked-by-issuer {01,04,05,06,07,31,34,41,42,43,46,57,58,59,62,63,67,70,75,79,83,93,1A,R,R1,R3}; invalid-details {03,13,14,15,55,56,78,80,82,86,92,N7}; other/technical fallback {12,19,22,84,91,96,P1,6P + any unknown}.
