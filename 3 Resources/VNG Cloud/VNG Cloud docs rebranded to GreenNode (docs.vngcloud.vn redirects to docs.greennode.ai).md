# VNG Cloud docs rebranded to GreenNode (docs.vngcloud.vn redirects to docs.greennode.ai)

VNG Cloud rebranded its documentation to **GreenNode**: 'docs.vngcloud.vn/...' URLs **307-redirect to 'docs.greennode.ai/...'** (same content). Product marketing still lives on vngcloud.vn; the console/calculator is under *.console.greennode.ai.

Zone gotcha found while researching: public compute/pricing docs are written for **HCM03-1A** (…/vserver/compute-hcm03-1a/…); there is **no public compute-hcm03-1c page** (404). An account limited to **HCM03-1C only** (1A/1B 'contact to enable') therefore has to confirm flavor availability + pricing parity with VNG directly, and cannot get cross-AZ HA on VKS despite VKS marketing multi-AZ.
