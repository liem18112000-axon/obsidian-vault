# Vietnamese Chirp3 TTS reads 'AI' as the word 'ai' — write 'tri tue nhan tao'

The Vietnamese Chirp3 HD voice (`vi-VN-Chirp3-HD-Leda`) pronounces the bare token "AI" as the Vietnamese word "ai" (meaning "who"), not the English letters. In any Vietnamese TTS script, replace "AI" with "trí tuệ nhân tạo" so it reads naturally. Keep genuine loanwords/brand names as-is (Obsidian, Quartz, Gemini, Vertex, GitHub, hook, skill, Claude, Markdown, wikilink).
