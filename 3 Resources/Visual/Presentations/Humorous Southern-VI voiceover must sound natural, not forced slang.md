# Humorous Southern-VI voiceover must sound natural, not forced slang

When writing the humorous Southern-Vietnamese (Miền Nam) voiceover for narrated decks, the persona is seasoning, not the dish — only use idioms/slang that actually collocate. A forced combination reads as wrong, not playful, and the user will flag it.

Real example flagged in the telegram deck: "Mình **nghịch** hook với skill cho Claude **đủ trò** rồi ha" — *nghịch…đủ trò* implies mischief/messing-around and is awkward. Natural fix: "Hook với skill cho Claude thì mình **vọc** cũng nhiều rồi ha. Bữa nay mình **chơi lớn** hơn:".

How to apply: read every VI block aloud (mentally) before rendering; prefer plain natural verbs (vọc, chơi lớn, dùng) over strained ones; use ONE good colloquial marker per sentence rather than piling them on. Markers that work: cả nhà ơi, nha, nè, ha, hông, xài, quất, chân ái. This is captured in the concept-to-video skill's references/voiceover-and-tts.md.
